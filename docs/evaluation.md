# 검색·답변 품질 평가

> 평가 코드: [`evaluation/`](../evaluation/) · 원본 결과: [`evaluation/results/`](../evaluation/results/)
> 이 문서에는 **실제로 실행한 결과만** 기록한다.

## 1. 평가 데이터

| 항목 | 내용 |
|---|---|
| 계약서 | 가상 계약서 4건 (용역·물품공급·업무위탁·비밀유지), 각 3페이지 — [contracts.py](../evaluation/datasets/contracts.py) |
| 질문 | 40개 — [questions.jsonl](../evaluation/datasets/questions.jsonl) |
| 유형 | 사실 15 · 조항 위치 4 · 여러 문장에 걸친 조건 6 · 비슷하지만 다른 조항 4 · 문서에 없는 정보 8 · 모호 3 |
| 정답 근거 | 원문 구절을 그대로 기록. 데이터셋 검증 테스트가 모든 구절이 원문에 있는지 확인한다 |

계약서는 서로 비슷하지만 다른 조항(해지/해제, 지체상금/손해배상/위약벌, 수수료 감액/손해배상 한도)을 일부러 섞어 구별 능력을 보도록 만들었다. 실제 계약서가 아니라 직접 작성한 데이터이므로 **실제 업무 문서에서의 성능을 대표하지 않는다.**

## 2. 지표

| 지표 | 정의 |
|---|---|
| 관련 청크 | 정답 근거 구절 중 하나라도 (공백 무시) 그대로 포함한 청크 |
| Recall@k | 상위 k개 안에 관련 청크가 하나라도 있는 질문의 비율 |
| Evidence coverage@k | 질문의 정답 근거 구절 중 상위 k개에 들어 있는 비율의 평균 (여러 조건을 모두 찾았는지) |
| MRR@10 | 첫 관련 청크 순위의 역수 평균 (10위 밖이면 0) |
| 임계값 통과율 / 차단율 | 최고 유사도 기준 — 답할 수 있는 질문이 통과하는 비율 / 문서에 없는 질문이 걸러지는 비율 |
| 답변률, 인용 적중률 | 답할 수 있는 질문에 답한 비율 / 인용한 청크에 정답 근거가 있는 비율 |
| 키워드 일치율 | 정답 핵심 표현이 답에 모두 들어 있는 비율 (표기가 다른 정답도 틀림으로 세는 엄격한 기준) |
| 거절률 | 문서에 없는 질문에 답하지 않은 비율 |
| 근거 없는 주장 발생률 | (문서에 없는 질문에 답한 수 + 정답 근거를 인용하지 못한 답 수) / 전체 답변 수 |
| 지연 | 질문 임베딩 + 검색 + 답변 생성 (평균, p50, p95) |

검색 점수(유사도)와 답변의 근거 일치는 별개로 측정한다. 유사도가 높아도 비슷한 다른 조항일 수 있기 때문이다.

## 3. 실험 절차

한 번에 한 변수만 바꾸고, 앞 단계에서 고른 값을 다음 단계의 고정값으로 쓴다.

1. **E1 청크 크기** 300 / 500 / 800 / 1200자 (겹침 100, 벡터 검색)
2. **E2 겹침** 0 / 50 / 100 / 200자 (E1에서 고른 크기)
3. **E3 top-k** 1 / 3 / 5 / 8
4. **E4 검색 방식** 벡터 / BM25(글자 2-gram) / 하이브리드(RRF)
5. **근거 부족 임계값** 0.15 ~ 0.60
6. **답변 평가** 고른 설정으로 40문항 전체를 실제 LLM으로 실행

선택 규칙: Recall@3 최대 → MRR@10 최대 → 더 작은 값(비용이 적은 쪽).

```bash
uv run python -m evaluation.run_retrieval_eval          # 1~5
uv run python -m evaluation.run_answer_eval --max-chars <E1> --overlap <E2> --top-k <E3> --min-score <임계값>
```

## 5. 해석 시 주의

- 질문 40개, 계약서 4건이라 수치의 분산이 크다. 한두 문항 차이로 비율이 2.5~5%p씩 움직인다.
- 정답 근거 판정은 "구절이 청크에 그대로 들어 있는가"이므로, 겹침이 없을 때 구절이 청크 경계에서 잘리면 관련 청크로 세지 않는다. 이것은 겹침의 효과를 보여 주는 의도된 기준이다.
- 키워드 일치율은 "300만 원"처럼 표기만 다른 정답도 틀림으로 센다.
